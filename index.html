Google Sheet Connection

पुराने Apps Script Web App URL और access token का उपयोग करें। URL पहले से भरा है; जरूरत हो तो यहाँ बदलें।

अभी तक Sync नहीं किया गया।

महत्वपूर्ण: Two-way sync के लिए Apps Script में GET read/list और POST upsert दोनों endpoints होने चाहिए। यदि पुराना Script केवल POST save करता है, तो “Google Sheet से लाएँ” तब तक काम नहीं करेगा जब तक Script में read सुविधा न जोड़ी जाए।
